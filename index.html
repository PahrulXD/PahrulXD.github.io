Pengertian Termux

Termux adalah aplikasi terminal emulator untuk Android yang memungkinkan pengguna menjalankan lingkungan Linux langsung di ponsel tanpa perlu akses root.

Perintah Dasar Termux

  • pkg update && pkg upgrade : Memperbarui pustaka sistem.
  • ls : Melihat daftar file/folder di direktori.
  • cd [nama_folder] : Masuk ke dalam folder tertentu.
  • cd .. : Kembali ke folder sebelumnya.
  • clear : Membersihkan layar terminal.

Perintah Install Utama

  • pkg install python : Menginstall bahasa Python.
  • pkg install git : Menginstall Git untuk mengunduh script dari GitHub.
  • pkg install bash : Menginstall pendukung script shell/bash.
